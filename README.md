# 🛒 CRUD de Gestión de Productos (.NET Core + Angular)

Aplicación Full Stack desarrollada como prueba técnica funcional para la gestión y administración de productos (CRUD completo).

## 🛠️ Tecnologías utilizadas

* **Backend:** .NET Core / C# (Web API)
* **Frontend:** Angular / TypeScript
* **Base de Datos:** SQL Server / Entity Framework

## ⚙️ Estructura del proyecto

* `BD/`: Scripts de creación de base de datos y tablas.
* `ExamenProductos/`: Web API RESTful en .NET Core.
* `Front/ExamenProductos/`: Cliente web spa en Angular.

## ✨ Funcionalidades claves

* Listado, creación, edición y eliminación lógica/física de productos.
* Validación de datos en backend y frontend.
* Integración REST API mediante servicios de Angular.

## 🚀 Instalación y ejecución local

### Backend (.NET Core)
1. Abrir la solución en Visual Studio.
2. Configurar la cadena de conexión en `appsettings.json`.
3. Ejecutar la API (`dotnet run` o F5 en Visual Studio).

### Frontend (Angular)
1. Navegar a la carpeta del frontend: `cd Front/ExamenProductos`
2. Instalar dependencias: `npm install`
3. Ejecutar la aplicación: `ng serve`
